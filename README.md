库存分配系统 (Inventory Allocation System)
一个基于 Web 的轻量级、自动化库存分配工具。该工具专为医药或商贸行业设计，能够根据客户额度比例，自动将不同批次的库存智能分配给各商业公司下的客户，并确保分配结果严格符合库存总量。

核心业务逻辑
系统遵循以下四大核心分配原则：

总量对齐原则：确保所有分配给客户的数量之和严格等于原始库存总量，不产生尾数误差。

额度优先原则：在同一商业公司下，剩余额度越大的客户优先获得分配。

批号先进先出 (FIFO)：对库存按批号进行升序排列，确保老批号（旧库存）优先被消耗。

行业分配惯例：

5的倍数取整：初步分配量会自动向下取整为5的倍数（如 154 盒取整为 150 盒）。

50盒起步原则：若按比例计算的分配量达到一定阈值（>=5），则至少分配 50 盒，避免配送成本过高。

尾数归集：分配产生的余数将自动归集至该商业公司下额度最大的客户。

功能特性
零后端依赖：完全基于 HTML5、CSS3 和原生 JavaScript 开发，所有计算在客户端完成，保障数据隐私。

Excel 深度集成：利用 SheetJS (XLSX) 库实现 Excel 文件的读取、解析与多表导出。

数据可视化预览：提供“分配结果”、“原始库存”、“原始客户额度”三个维度的实时数据切换预览。

智能日期处理：自动识别并转换 Excel 内部的日期序列号格式。

自动对账校验：分配完成后自动对比总金额、总量，并以颜色标识校验状态。

技术栈
前端框架: 原生 JavaScript (ES6+)

UI 样式: 原生 CSS (响应式布局、粘性表头)

数据处理: SheetJS (xlsx.full.min.js)

快速上手
1. 准备数据源
上传的 Excel 文件需包含两个工作表（Sheet）：

工作表 1 (库存数据)：需包含列：商业公司、产品名称、产品批号、库存总量、生产日期、有效期至、单价。

工作表 2 (客户数据)：需包含列：商业公司、客户名称、剩余额度。

2. 执行分配
打开 index.html。

点击 “选择文件” 上传准备好的 Excel。

点击 “执行分配”，系统将自动切换至“分配结果”标签页。

查看底部的系统摘要，确认“分配总量等于库存总量”状态为绿色。

3. 结果导出
点击 “导出Excel”，系统将生成一份包含三张完整表单的新 Excel 文件，方便后续业务入账。
